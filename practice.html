Coding Practice

1. Create a Doubly Linked List node

Write createNode(int v). Input: 10 Expected: node with data 10, prev NULL, next NULL.

Hint

Use malloc(sizeof(struct Node)) and set both pointers to NULL.

Solution
struct Node* createNode(int v) {
    struct Node* n = (struct Node*)malloc(sizeof(struct Node));
    n->data = v; n->prev = NULL; n->next = NULL;
    return n;
}
2. Insert a node at the beginning

Input: list 20 ⇄ 30, insert 10. Expected: 10 ⇄ 20 ⇄ 30.

Hint

Set n->next = head before changing head. Update head->prev if head exists.

Solution
void insertBegin(int v) {
    struct Node* n = createNode(v);
    n->next = head;
    if (head != NULL) head->prev = n;
    head = n;
}
3. Insert a node at the end

Input: list 10 ⇄ 20, insert 30. Expected: 10 ⇄ 20 ⇄ 30.

Hint

Walk until t->next == NULL, then link both directions.

Solution
void insertEnd(int v) {
    struct Node* n = createNode(v);
    if (head == NULL) { head = n; return; }
    struct Node* t = head;
    while (t->next != NULL) t = t->next;
    t->next = n; n->prev = t;
}
4. Delete a node with a given value

Input: 10 ⇄ 20 ⇄ 30, delete 20. Expected: 10 ⇄ 30.

Hint

Find the node, then make its neighbours point to each other.

Solution
void deleteValue(int v) {
    struct Node* t = head;
    while (t != NULL && t->data != v) t = t->next;
    if (t == NULL) return;
    if (t->prev != NULL) t->prev->next = t->next; else head = t->next;
    if (t->next != NULL) t->next->prev = t->prev;
    free(t);
}
5. Display forward and backward

Input: 10 ⇄ 20 ⇄ 30. Expected: 10 20 30 and 30 20 10.

Hint

Backward: first walk to the tail, then follow prev.

Solution
for (t = head; t != NULL; t = t->next) printf("%d ", t->data);
t = head; while (t->next != NULL) t = t->next;
for (; t != NULL; t = t->prev) printf("%d ", t->data);

Important Viva Questions

What is a Doubly Linked List?

A list whose nodes store data, a prev pointer and a next pointer.

What does a node contain?

prev, data, next.

Why do we use the prev pointer?

To move backward and to delete a known node quickly.

Difference between singly and doubly lists?

Singly has only next and goes one way. Doubly has prev and next and goes both ways, using more memory.

Time complexity of insertion at beginning?

O(1).

What happens when head is NULL?

The list is empty. Traversal and deletion must be avoided or handled.

Why is NULL used?

It marks the end: first->prev and last->next are NULL.

What are the applications?

Browser history, undo/redo, playlists, image viewers, LRU cache.

Why is deleting a known node O(1)?

prev gives the previous node directly, so no search is needed.

Why call free()?

To release memory and avoid a leak.

Can a DLL be circular?

Yes. Last->next points to head and head->prev points to last.

Which uses more memory, singly or doubly?

Doubly, because of the extra prev pointer.

How do you traverse backward?

Go to the tail, then keep doing t = t->prev until NULL.

Cost of searching?

O(n).

Cost of insertion at end with a tail pointer?

O(1).

First step when inserting after node temp?

newNode->next = temp->next, so the rest of the list is not lost.

What is a memory leak?

Allocated memory that is never freed.

Can we reverse a DLL?

Yes, swap prev and next in every node and move head to the old tail.

Is random access possible?

No, you must traverse from head or tail.

Space complexity?

O(n).
