Learn Doubly Linked List

What is a Linked List?

A linked list stores items in separate boxes called nodes. Each node holds a value and the address of another node, so the nodes are "linked" like train coaches.

What is a Doubly Linked List?

Every node has two links: prev (the node before it) and next (the node after it).

PREV10NEXT

PREV20NEXT

  • PREV: address of the previous node (NULL for the first node).
  • DATA: the stored value.
  • NEXT: address of the next node (NULL for the last node).
  • head points to the first node; NULL means "nothing here".

Node Structure in C

struct Node {
    int data;            // the value stored in the node
    struct Node* prev;   // address of the previous node
    struct Node* next;   // address of the next node
};

struct Node defines a new type. int data holds the value. prev and next are pointers to another struct Node, which is what links nodes together. In memory each node is one block: [ prev | data | next ].

How it works

  1. Create a node with malloc and set data; prev and next start as NULL.
  2. Connect nodes: a->next = b and b->prev = a (always both).
  3. prev pointer lets you move one step back.
  4. next pointer lets you move one step forward.
  5. Forward traversal: start at head, print, move t = t->next until NULL.
  6. Backward traversal: go to the tail, print, move t = t->prev until NULL.
  7. Insert: link the new node to both neighbours, then update both neighbours.
  8. Delete: make the neighbours point to each other, then free the node.

Operations

Open each one. Try them live in the Visualizer.

Create List

Start with head = NULL; the first insertion creates the first node.

Time: O(1)

Insert at Beginning
  1. Create newNode
  2. newNode->next = head
  3. newNode->prev = NULL
  4. If head exists: head->prev = newNode
  5. head = newNode

Time: O(1)

Example: 20 ⇄ 30, insert 10 gives 10 ⇄ 20 ⇄ 30.

Insert at End
  1. Create newNode
  2. If empty: head = newNode
  3. Else move temp to the last node
  4. temp->next = newNode; newNode->prev = temp

Time: O(n), or O(1) with a tail pointer

Insert at Position
  1. Create newNode
  2. Move temp to node at position-1
  3. newNode->next = temp->next; newNode->prev = temp
  4. If temp->next exists: temp->next->prev = newNode
  5. temp->next = newNode

Time: O(n)

Example: 10 ⇄ 20 ⇄ 30, insert 25 at position 3 gives 10 ⇄ 20 ⇄ 25 ⇄ 30.

Delete from Beginning
  1. temp = head
  2. head = head->next
  3. If head exists: head->prev = NULL
  4. free(temp)

Time: O(1)

Delete from End
  1. Move temp to the last node
  2. If temp->prev exists: temp->prev->next = NULL, else head = NULL
  3. free(temp)

Time: O(n), or O(1) with a tail pointer

Delete from Position
  1. Move temp to the node
  2. temp->prev->next = temp->next
  3. If temp->next exists: temp->next->prev = temp->prev
  4. free(temp)

Time: O(n)

Forward and Backward Traversal

Forward: for (t = head; t; t = t->next). Backward: go to the tail, then for (; t; t = t->prev).

Time: O(n)

Complete Menu-Driven C Program

This code is for learning. It is not compiled in the browser. Copy it and run with gcc dll.c -o dll.

#include <stdio.h>
#include <stdlib.h>

struct Node { int data; struct Node *prev, *next; };
struct Node* head = NULL;

struct Node* createNode(int v) {
    struct Node* n = (struct Node*)malloc(sizeof(struct Node));
    if (n == NULL) { printf("Memory error\n"); exit(1); }
    n->data = v; n->prev = NULL; n->next = NULL;
    return n;
}
void insertBegin(int v) {
    struct Node* n = createNode(v);
    n->next = head;
    if (head != NULL) head->prev = n;
    head = n;
}
void insertEnd(int v) {
    struct Node* n = createNode(v);
    if (head == NULL) { head = n; return; }
    struct Node* t = head;
    while (t->next != NULL) t = t->next;
    t->next = n; n->prev = t;
}
void insertPos(int v, int pos) {
    if (pos < 1) { printf("Invalid position\n"); return; }
    if (pos == 1) { insertBegin(v); return; }
    struct Node* t = head;
    for (int i = 1; i < pos - 1 && t != NULL; i++) t = t->next;
    if (t == NULL) { printf("Invalid position\n"); return; }
    struct Node* n = createNode(v);
    n->next = t->next; n->prev = t;
    if (t->next != NULL) t->next->prev = n;
    t->next = n;
}
void deleteBegin() {
    if (head == NULL) { printf("List is empty\n"); return; }
    struct Node* t = head;
    head = head->next;
    if (head != NULL) head->prev = NULL;
    free(t);
}
void deleteEnd() {
    if (head == NULL) { printf("List is empty\n"); return; }
    struct Node* t = head;
    while (t->next != NULL) t = t->next;
    if (t->prev != NULL) t->prev->next = NULL; else head = NULL;
    free(t);
}
void deletePos(int pos) {
    if (head == NULL) { printf("List is empty\n"); return; }
    if (pos < 1) { printf("Invalid position\n"); return; }
    if (pos == 1) { deleteBegin(); return; }
    struct Node* t = head;
    for (int i = 1; i < pos && t != NULL; i++) t = t->next;
    if (t == NULL) { printf("Invalid position\n"); return; }
    t->prev->next = t->next;
    if (t->next != NULL) t->next->prev = t->prev;
    free(t);
}
void forward() {
    struct Node* t = head;
    printf("NULL"); while (t != NULL) { printf(" <-> %d", t->data); t = t->next; }
    printf(" -> NULL\n");
}
void backward() {
    struct Node* t = head;
    if (t == NULL) { printf("List is empty\n"); return; }
    while (t->next != NULL) t = t->next;
    printf("NULL"); while (t != NULL) { printf(" <-> %d", t->data); t = t->prev; }
    printf(" -> NULL\n");
}
int main() {
    int ch, v, p;
    do {
        printf("\n1.Insert Begin 2.Insert End 3.Insert Pos 4.Delete Begin\n");
        printf("5.Delete End 6.Delete Pos 7.Forward 8.Backward 9.Display 10.Exit\nChoice: ");
        scanf("%d", &ch);
        switch (ch) {
            case 1: printf("Value: "); scanf("%d", &v); insertBegin(v); break;
            case 2: printf("Value: "); scanf("%d", &v); insertEnd(v); break;
            case 3: printf("Value and position: "); scanf("%d %d", &v, &p); insertPos(v, p); break;
            case 4: deleteBegin(); break;
            case 5: deleteEnd(); break;
            case 6: printf("Position: "); scanf("%d", &p); deletePos(p); break;
            case 7: case 9: forward(); break;
            case 8: backward(); break;
            case 10: break;
            default: printf("Invalid choice\n");
        }
    } while (ch != 10);
    return 0;
}

Time and Space Complexity

OperationTime
Insert BeginningO(1)
Insert EndO(1) if tail exists, else O(n)
Insert PositionO(n)
Delete BeginningO(1)
Delete EndO(1) if tail exists, else O(n)
Delete PositionO(n)
Forward / Backward TraversalO(n)
SearchO(n)

Best case: the target is at the head (or tail with a tail pointer): O(1). Average: about n/2 steps, still O(n). Worst case: the target is at the far end: O(n). Space: O(n) for n nodes, plus one extra pointer per node compared with a singly list.

Advantages and Disadvantages

Advantages

  • Forward and backward traversal
  • Easy deletion when the node is known
  • Flexible insertion and deletion
  • Bidirectional navigation

Disadvantages

  • Extra memory for prev
  • More pointer manipulation
  • More complex than singly list

Real-World Applications

  • Browser history: Back goes to prev, Forward goes to next.
  • Undo/Redo: undo moves to the previous state, redo to the next.
  • Music playlist: previous song and next song buttons.
  • Image viewer: left and right arrows through photos.
  • Navigation systems: move to the next or previous stop on a route.
  • LRU cache: a node is removed from its place and moved to the front in O(1).

Common Pointer Mistakes

  • Forgetting to update prev: the backward chain breaks. Wrong: t->next = n; only. Right: also n->prev = t;
  • Forgetting to update next: forward traversal skips the new node.
  • Losing head: assigning head = n before n->next = head loses the old list.
  • Wrong NULL handling: t->next->prev crashes when t->next is NULL. Check first.
  • Deleting without reconnecting neighbours: they still point to freed memory.
  • Invalid memory access: using a node after free().
  • Not checking an empty list: always test head == NULL.
